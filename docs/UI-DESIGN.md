# AICC Mini - UI Design

## 전체 레이아웃 구조

```
┌─────────────────────────────────────────────────┐
│  Header (fixed top, h-14)                        │
│  [Logo]  [Page Title]   [Notifications] [User▼] │
├──────────┬──────────────────────────────────────┤
│          │                                      │
│ Sidebar  │  Main Content Area                   │
│ (fixed,  │  (scrollable)                        │
│  w-60)   │                                      │
│          │                                      │
└──────────┴──────────────────────────────────────┘
```

- `(auth)` 그룹 (로그인 페이지): 중앙 정렬 카드, Sidebar/Header 없음
- `(main)` 그룹: Sidebar + Header 항상 표시

## 공통 컴포넌트 목록

### Layout

| 컴포넌트 | 파일 | 설명 |
|---------|------|------|
| Sidebar | `components/layout/Sidebar.tsx` | 좌측 네비게이션, 역할별 메뉴 표시 |
| Header | `components/layout/Header.tsx` | 상단 바, 알림 벨, 유저 드롭다운 |

### Tickets

| 컴포넌트 | 설명 |
|---------|------|
| TicketStatusBadge | open(회색)/in_progress(파랑)/resolved(초록)/closed(검정) 컬러 배지 |
| PriorityBadge | low(회색)/medium(노랑)/high(주황)/urgent(빨강) 컬러 배지 |
| TicketFilters | 상태·우선순위·담당자·키워드 복합 필터 폼 |
| TicketCard | 목록용 행 (배지들 포함) |
| TicketForm | 생성/수정 폼 (react-hook-form + zod) |
| CommentList | 댓글 목록, 내부메모는 배경색 구분 |
| CommentForm | 댓글 입력 + 내부메모 체크박스 |
| AttachmentMeta | URL 기반 첨부파일 링크 목록 |

### KB

| 컴포넌트 | 설명 |
|---------|------|
| ArticleCard | 문서 카드 (제목, 태그 칩, 버전, 날짜) |
| ArticleEditor | 마크다운 textarea 편집기 |
| TagManager | 태그 인라인 추가/제거 (칩 UI) |
| SearchBar | 키워드 검색 입력 (debounce) |

### Rules

| 컴포넌트 | 설명 |
|---------|------|
| RuleList | 룰 테이블 (토글, 편집, 삭제) |
| RuleForm | 조건+액션 설정 폼 (모달) |
| RuleToggle | shadcn Switch 컴포넌트 래핑 |

### Dashboard

| 컴포넌트 | 설명 |
|---------|------|
| StatsCard | 숫자 + 레이블 + 추세 아이콘 카드 |
| StatusChart | 상태별 도넛 차트 (Recharts PieChart) |
| PriorityChart | 우선순위별 바 차트 (Recharts BarChart) |
| RecentTickets | 최근 10건 티켓 테이블 |

### Notifications

| 컴포넌트 | 설명 |
|---------|------|
| NotificationItem | 단일 알림 행 (읽음/미읽음 점, 타입 아이콘) |
| NotificationList | 목록 + 전체 읽음 버튼 |
| NotificationBell | Header 내 알림 아이콘 + 미읽음 카운트 배지 |

### Audit

| 컴포넌트 | 설명 |
|---------|------|
| AuditLogTable | 로그 테이블, 행 클릭 시 before/after 펼치기 |

## 페이지 간 네비게이션 흐름

```
/login
  └─[로그인 성공]──→ /dashboard

/dashboard
  └─[최근 티켓 클릭]──→ /tickets/[id]
  └─[사이드바]──→ 모든 페이지

/tickets
  └─[+ 티켓 생성]──→ /tickets/new
  └─[행 클릭]──→ /tickets/[id]

/tickets/new
  └─[생성 성공]──→ /tickets/[id] (새 티켓)
  └─[취소]──→ /tickets

/tickets/[id]
  └─[← 목록]──→ /tickets

/kb
  └─[카드 클릭]──→ /kb/[id]
  └─[+ 새 문서]──→ /kb/new (또는 모달)

/kb/[id]
  └─[편집]──→ /kb/[id]/edit (agent+만)
  └─[← 목록]──→ /kb

/kb/[id]/edit
  └─[저장]──→ /kb/[id]
  └─[취소]──→ /kb/[id]

/notifications
  └─[티켓 바로가기]──→ /tickets/[id]
```

## 주요 UI 패턴

### 상태 배지 컬러 시스템

```
상태:
  open          → bg-gray-100   text-gray-700
  in_progress   → bg-blue-100   text-blue-700
  resolved      → bg-green-100  text-green-700
  closed        → bg-gray-800   text-white

우선순위:
  low           → bg-gray-100   text-gray-600
  medium        → bg-yellow-100 text-yellow-700
  high          → bg-orange-100 text-orange-700
  urgent        → bg-red-100    text-red-700
```

### 폼 패턴

- shadcn/ui `Form` + `react-hook-form` + `zod` 스키마
- 필드 에러: 필드 아래 빨간 텍스트
- 제출 중: 버튼 `disabled` + 스피너
- 성공: `router.push()` 또는 `router.refresh()`

### 모달 패턴

- shadcn/ui `Dialog` 사용
- 룰 생성/편집, 확인 팝업(삭제 확인)에 사용
- 슬라이드오버: 복잡한 폼에 선택적 사용

### 빈 상태 (Empty State)

```
┌─────────────────────────────────────┐
│        [아이콘]                     │
│   [엔티티명]이 없습니다.             │
│   [첫 번째 아이템 만들기 →]          │
└─────────────────────────────────────┘
```

### 로딩 상태

- 페이지 레벨: `loading.tsx` → shadcn Skeleton 컴포넌트
- 버튼 레벨: `disabled` + `Loader2` 스피너 아이콘
- 인라인: 테이블 행 스켈레톤

### 차트 패턴 (Recharts)

- `ResponsiveContainer` 항상 사용 (반응형)
- StatusChart: `PieChart` + `Cell` 컬러 매핑 (상태 컬러와 일치)
- PriorityChart: `BarChart` 수평 (우선순위 컬러와 일치)
- 툴팁: 커스텀 `CustomTooltip` 컴포넌트

### 역할별 UI 제어

- `session.user.role === 'admin'` → Settings 메뉴 표시
- `session.user.role !== 'viewer'` → 편집/생성 버튼 표시
- 권한 없는 버튼: 렌더링 자체를 하지 않음 (disabled X, hidden O)
